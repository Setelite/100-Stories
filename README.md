# 100 дней без сценария

Готовое автономное мини-приложение (PWA) с 100 сценариями сторис и 29 идеями для Reels, прогрессом, заметками и иконкой для iPhone.

## Разместить на GitHub Pages

1. Создайте новый **публичный** репозиторий на github.com, например `100-dney`.
2. Загрузите **все файлы из этой папки** в корень репозитория (`index.html`, `styles.css`, `app.js`, `data.js`, `manifest.webmanifest`, `sw.js`, каталог `icons`). **Не загружайте ZIP одним файлом**: его нужно сначала распаковать.
3. Откройте **Settings → Pages → Build and deployment**, выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Сохраните.
4. Сайт появится по адресу вида `https://ВАШ_ЛОГИН.github.io/100-dney/` после публикации Pages.
5. Откройте эту ссылку **в Safari на iPhone** → кнопка «Поделиться» → «На экран „Домой“» → «Добавить». Появится иконка «100 дней».

## Что умеет

- Главная с заданием актуального дня (часовой пояс Екатеринбурга), прогрессом и ближайшими днями.
- 100 тем с тремя блоками: начало, основная мысль и завершение; копирование сценария.
- Статусы «Не выполнено», «Выполнено», «Пропущено»; обратимое изменение.
- Поиск, фильтры, категории, заметки к каждому дню.
- Отдельный список 29 Reels с отметками публикаций.
- Процент выполнения, серии дней, этапы по 10, статистика.
- Сохранение прогресса в `localStorage`, экспорт/импорт резервной копии JSON.
- Офлайн-режим после первого успешного открытия через HTTPS (Service Worker).

## Важно

- Данные хранятся **только в том браузере / установленном приложении, где вы отмечаете дни**. Синхронизация с iCloud и между устройствами не реализована. Регулярно нажимайте «Экспорт JSON» в настройках.
- При удалении данных Safari, смене домена или удалении приложения отметки могут исчезнуть.
- Сам сайт **не отправляет push-уведомления**. Напоминания на 08:30 и Reels на 19:00 уже предусмотрены в ранее созданных событиях Google/Apple Календаря.
- На хостинге не нужны PHP, база данных, серверная часть или токены.
- Начало: **26 октября 2026 года**, 100-й день — **2 февраля 2027 года**. В приложении вычисляется дата Екатеринбурга независимо от часового пояса устройства.

## Обновления

При изменении JavaScript или CSS обновляйте константу `CACHE` в `sw.js` (например, на `100-days-v2`), чтобы установленная версия могла скачать новые файлы. `data.js` редактируется вручную (там содержатся все сценарии).
